# Research Roadmap

Near-term research:
- Canonical-view silhouette correction.
- Side/back authority promotion from authored views.
- Semantic silhouette drift constraints.
- Surface-normal stylisation for NPR readability.

Later research:
- Better low-poly remeshing after silhouette correction.
- Optional authored normal fields.
- Rigging hooks after canonical view stability.
- Higher resolution profiles, including 32-bit and 64-bit model budgets, only after validation remains stable.

Out of scope for the current runtime:
- Runtime generative AI.
- Animation and rigging.
- Full production anime shading.
- Public deployment assumptions.
