# Validation Contract

Every promoted build path must produce machine-readable validation reports.

Required report classes:
- Source coverage and view authority.
- Semantic override coverage and conflicts.
- Depth and seam closure.
- SDF and mesh topology.
- Godot render visibility.
- Canonical-view silhouette metrics.

Validation must identify known limitations numerically. The current expected limitation is front-derived/inferred side and back geometry.
