# Studio Contract

SpriteSpatial Studio is an authoring and inspection layer, not a hidden generator.

Locked behaviour:
- Users should see source coverage, semantic overrides, canonical-view targets, and validation warnings.
- AI may rank or classify candidate crops, but must not silently mutate art.
- Copying or promoting candidate views requires explicit user confirmation.
- Studio outputs must be explicit asset files and manifests.

Future Studio work should expose diagnostics before offering correction tools.
